# $\fbox{HIERARCHIES}$





## **Topic - 1: Indian Army**

### <u>Officers & Roles</u>

| Rank                   | Typical Command/Role                             |
| ---------------------- | ------------------------------------------------ |
| **Lieutenant**         | Platoon / troop-level leadership                 |
| **Captain**            | Company second-in-command or equivalent          |
| **Major**              | Company commander / staff appointment            |
| **Lieutenant Colonel** | Battalion commander                              |
| **Colonel**            | Brigade staff/command and senior appointments    |
| **Brigadier**          | Brigade commander                                |
| **Major General**      | Division commander                               |
| **Lieutenant General** | Corps commander / senior Army HQ appointment     |
| **General**            | Chief of the Army Staff (COAS)                   |
| **Field Marshal**      | Five-star ceremonial rank; exceptionally awarded |


### <u>JCOs</u>

- *Naib Subedar* $\rightarrow$ *Subedar* $\rightarrow$ *Subedar Major*.
- Linkage between officers & enlisted personnel at company/battalion level.


### <u>NCOs</u>

- *Sepoy*, *Lance Naik* $\rightarrow$ *Naik* $\rightarrow$ *Havildar*.


### <u>Formation Hierarchy</u>

| Formation     |             Approx. size | Typical commander        |
| ------------- | -----------------------: | ------------------------ |
| **Section**   |                     8–10 | Havildar/Naik            |
| **Platoon**   |                    30–40 | Lieutenant/Captain       |
| **Company**   |                  100–150 | Major/Lieutenant Colonel |
| **Battalion** |                  600–900 | Colonel                  |
| **Brigade**   |           3–5 battalions | Brigadier                |
| **Division**  |             3–4 brigades | Major General            |
| **Corps**     |            3–4 divisions | Lieutenant General       |
| **Command**   | Multiple corps/divisions | Lieutenant General       |


### <u>Commands & HQs</u>

| Command                   | Type        | Headquarters             | Broad area / role                                     |
| ------------------------- | ----------- | ------------------------ | ----------------------------------------------------- |
| **Northern Command**      | Operational | Udhampur, J&K            | Ladakh and J&K sectors                                |
| **Western Command**       | Operational | Chandimandir, Haryana    | Western/Pakistan-facing sector                        |
| **South-Western Command** | Operational | Jaipur, Rajasthan        | Southwestern/western sector                           |
| **Eastern Command**       | Operational | Kolkata, West Bengal     | Eastern/north-eastern sector                          |
| **Central Command**       | Operational | Lucknow, Uttar Pradesh   | Central/northern-central area                         |
| **Southern Command**      | Operational | Pune, Maharashtra        | Southern India                                        |
| **ARTRAC**                | Training    | Shimla, Himachal Pradesh | Army training, doctrine and institutional development |
